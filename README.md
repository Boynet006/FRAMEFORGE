# FRAMEFORGE — Local AI Video Studio

One prompt in, a complete MP4 out, generated entirely on local hardware
(target: NVIDIA RTX 5080, 16 GB VRAM). See [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md)
for the current phase and [docs/PHASE0_ENVIRONMENT_REPORT.md](docs/PHASE0_ENVIRONMENT_REPORT.md)
for the model and VRAM strategy.

## Layout

```
backend/    FastAPI orchestration API (Python 3.12+), SQLite project/job store
frontend/   Next.js + TypeScript + Tailwind dashboard
scripts/    Windows PowerShell helpers (environment probe, dev servers)
docs/       Status, environment report, install plan
```

## Continue on another computer

Everything needed is in the repository (code, docs, `CLAUDE.md` with the project context for
Claude Code). Generated media and model files are not; they are rebuilt locally.

```powershell
git clone https://github.com/Boynet006/FRAMEFORGE.git
```

Then follow the prerequisites and the engine setup below, open Claude Code in the folder, and it
will read `CLAUDE.md` and `docs/PROJECT_STATUS.md` for where things stand. Commit and push after
each step so the next machine stays current.

## Prerequisites (Windows)

- Python 3.12 (`py -3.12 --version`) — used for the backend and the AI workers
- Node.js LTS 20+ and npm (`node --version`)
- Git, FFmpeg 7+ on PATH (`ffmpeg -version`)
- Ollama with the planning model (`ollama pull qwen3:4b` on CPU machines, `qwen3:14b` on the RTX 5080 PC)
- ComfyUI on `http://127.0.0.1:8188`

Install with winget:

```powershell
winget install --id Python.Python.3.12 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Git.Git -e
winget install --id Gyan.FFmpeg -e
winget install --id Ollama.Ollama -e
```

Then, from the repository root (new terminal so PATH is fresh):

```powershell
ollama pull qwen3:4b
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-workers.ps1
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-comfyui-cpu.ps1
```

The last script installs ComfyUI in CPU mode with Stable Diffusion 1.5 + LCM (about 2.3 GB of
models) into `C:\AI\ComfyUI`. Start ComfyUI with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run-comfyui-cpu.ps1
```

**NVIDIA GPU machines** (RTX 4090 laptop, RTX 5080): pull `qwen3:14b` instead of `qwen3:4b`, set
`FRAMEFORGE_OLLAMA_MODEL=qwen3:14b` and `FRAMEFORGE_IMAGE_WORKFLOW=image_sdxl` in `backend\.env`, and
install ComfyUI with CUDA PyTorch (adds SDXL base 1.0, about 7 GB, to the CPU install's models):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-comfyui-gpu.ps1 -S2V
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run-comfyui-gpu.ps1
```

`-S2V` also downloads Wan 2.2 S2V (about 24 GB) for real lip-sync. Set
`FRAMEFORGE_RENDER_MODE=gpu` in `backend\.env` to use it: every speaking shot is then generated by
the S2V model from the shot's first frame and the line's audio (about 1.5–3 minutes per 5 seconds of
speech on a 16 GB laptop GPU), while establishing and reaction shots stay procedural.

The video-model GPU sequence (Wan 2.2) is in `docs/PHASE0_INSTALL_PLAN.md`.

## Run the development servers

Open two PowerShell windows in the repository root.

Backend (creates the venv, installs requirements and `.env` on first run):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dev-backend.ps1
```

Success: a log line `FRAMEFORGE backend 0.1.0 started`, and
`http://127.0.0.1:8000/api/health` returns JSON with `"status": "ok"`.
Interactive API docs: `http://127.0.0.1:8000/docs`.

Frontend (installs node_modules and `.env.local` on first run):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dev-frontend.ps1
```

Success: `Ready` in the console; `http://localhost:3000` shows the dashboard with the backend
card green and the ComfyUI card reporting its real reachability.

## Configuration

Backend settings live in `backend/.env` (copy from `backend/.env.example`). All variables are
prefixed `FRAMEFORGE_`. The important one for Phase 1 is `FRAMEFORGE_COMFYUI_URL`.

Frontend settings live in `frontend/.env.local` (copy from `frontend/.env.local.example`):
`NEXT_PUBLIC_API_URL` must point at the backend.

## Workflow templates

Templates live in `backend/workflows/<name>.v<N>.json`: an API-format ComfyUI graph plus an
`inputs` manifest mapping parameter names to node fields. Add a new version as a new file; the
API serves the latest unless a version is requested. `validated: false` marks templates that
have not yet been run on real hardware. `POST /api/workflows/reload` re-reads the folder.

To try the UI without a GPU, run the stand-in ComfyUI from `backend/`:

```powershell
.\.venv\Scripts\python.exe -m tests.fake_comfy --port 8188
```

It mimics the real API shapes and produces placeholder files. It is for development only.

## How a video is made (CPU mode)

1. **Script** — Ollama writes an outline, then dialogue per scene, constrained by JSON schemas, and
   tops up short scripts until the estimated runtime is near the target.
2. **Voices** — Kokoro speaks every line (distinct voice per character) and produces a timeline with
   word timestamps, pauses and scene gaps, plus a mixed dialogue track.
3. **References** — ComfyUI renders one portrait per character and one wide image per environment.
4. **Animate** — the animator cuts characters out (rembg), finds faces (OpenCV), plans shots
   (establishing, shot/reverse-shot, reaction cut-ins, two-shots) and renders frames with
   audio-driven mouth movement, blinks, head motion and camera moves.
5. **Assemble** — FFmpeg burns subtitles, mixes procedural music under the dialogue and writes
   `render/final.mp4`; ffprobe checks duration and streams.

Every stage leaves its outputs on disk under `backend/data/projects/<id>/`, so a re-run resumes
where it stopped. On the RTX 5080 PC stage 4 is meant to use ComfyUI video models instead.

## Troubleshooting

- **`py` not found**: install Python from python.org or winget; make sure "py launcher" is selected.
- **`node` not found after installing**: open a new terminal so PATH refreshes.
- **Backend starts but the frontend shows "backend unreachable"**: check `NEXT_PUBLIC_API_URL` in
  `frontend/.env.local` matches the backend host/port, and that `FRAMEFORGE_CORS_ORIGINS` in
  `backend/.env` includes `http://localhost:3000`.
- **ComfyUI card red**: expected until ComfyUI is installed and running on the configured URL.
  Start ComfyUI, then the card refreshes on its own.
- **Port already in use**: change `FRAMEFORGE_PORT` / `--port` and update `NEXT_PUBLIC_API_URL`.
- **Voices stage fails with "cannot start line worker"**: `backend/.venv-tts` is missing; run
  `scripts\install-workers.ps1`.
- **Script stage fails with "model not found"**: `ollama pull <model>` for the model named in
  `FRAMEFORGE_OLLAMA_MODEL`.
- **References stage fails with "ComfyUI rejected the graph"**: the checkpoint or LoRA file named in
  the template is missing from ComfyUI's `models/` folders.
- **Assemble fails mentioning `subtitles`**: your FFmpeg build lacks libass; install the "full" build.
